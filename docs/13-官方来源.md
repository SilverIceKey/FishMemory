# 13. 官方来源、核验状态与引用要求

> 本文件是研发依赖核验台账，更新核验：**2026-10-30**（原稿 2026-10-29）。上游版本变化快，开发时需锁定实际 tag/commit，再逐项确认。

## 已查到的官方来源

### DeepSeek Harness（官方）

- 仓库 README（插件式架构、预览状态及不稳定性）：https://github.com/deepseek-ai/deepseek-harness
- 插件扩展 cookbook（hook 能力地图）：https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/cookbook/extension-cookbook.md
- Tool 开发参考（`ctx.tools.register`、`defineTool` 能力）：https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/cookbook/adding-a-tool.md
- dsh-tools 包 README（工具注册、呈现/执行机制）：https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/core/tools/README.md
- MCP Client 包 README（MCP 桥接、transport、命名规则）：https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/mcp/mcp-client/README.md
- MCP Client 源码入口：https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/mcp/mcp-client/src/index.ts

**注意：这些链接默认指向 `master`，不能代替版本锁定。** 看到当前支持的能力，不等于某个已经安装的旧发行版同样支持。存在不同材料对工具呈现模式名称描述不一致的可能，必须以所锁定的包和源码为准。

### MCP（官方）

- 2026-07-28 Tools 规范：https://github.com/modelcontextprotocol/modelcontextprotocol/blob/main/docs/specification/2026-07-28/server/tools.mdx
- 官方协议仓库：https://github.com/modelcontextprotocol/modelcontextprotocol

MCP 提供工具描述/调用协议，不自动定义 FishMemory 的持久化、授权删除、记忆质量或成本目标。`memory_recall` 和业务 JSON schema 均为本项目设计。

### SQLite（官方）

- FTS5 文档：https://www.sqlite.org/fts5.html
- WAL 文档：https://www.sqlite.org/wal.html
- 备份 API 文档：https://www.sqlite.org/backup.html

注意验证实际打包 SQLite 构建是否支持 FTS5；中文搜索质量需单独测，不将默认 tokenizer 能力想象成通用语义搜索。

### Qwen 模型

- Qwen 官方模型组织：https://huggingface.co/Qwen
- 官方模型卡：https://huggingface.co/Qwen/Qwen3.5-0.8B （已确认默认 Non-Thinking、`enable_thinking` 的官方 API 示例、Thinking 循环风险、以及 `/think`/`/nothink` 不被官方支持；**模型权重 revision、量化及实际运行时仍需锁定**）。

## 研发团队必须补全的版本证据

- DSH：实际 package/tag/commit、Node 和包管理器版本、hook 核对的源码行/测试结论。
- MCP：实际 SDK 版本、支持协议版本、transport、工具发现与返回格式。
- 本地模型：仓库/权重 revision、tokenizer revision、量化格式、运行时版本、输入输出结构化能力。
- SQLite：库版本、是否编译 FTS5、中文 tokenizer 决策。

## 事实等级

- **官方明确**：附上与所锁定版本匹配的官方 URL/代码位置。
- **用户需求**：引用本项目决策文档。
- **工程建议**：表明是可测试的初始设计，不包装为标准强制要求。
- **待验证**：明确未验证、评估方法及阻断后果。


## 本次补充核实的直接来源与能证明的结论

| 来源 | 能支持的具体断言 | 不能直接支持的断言 |
|---|---|---|
| https://huggingface.co/Qwen/Qwen3.5-0.8B | 官方模型卡：0.8B 默认 Non-Thinking；支持通过推理参数显式开启 Thinking；Thinking 易出现循环；不支持 Qwen3 风格软切换 | 任意第三方运行时都兼容 `enable_thinking=false`；具体量化速度必然达标 |
| https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/mcp/mcp-client/README.md | 官方 MCP Client：`stdio`/`streamable-http`、`serverName`、`transport`、`url` 和工具名前缀，以及重连/启动处理 | 使用 MCP 即可自动捕获并可靠归档 DSH 会话 |
| https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/core.md | `agent/pre-step` 可以替换进入本步骤的消息 | 默认只触发一次、注入不会落会话历史 |
| https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/session.md | `session/event` 是 post-commit、fire-and-forget 观察通知 | 事件已送达 FishMemory 数据库并获得 ACK |
| https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/architecture.md | `agent.inject()` 是一种模型可见上下文注入机制 | 可无副作用替代所有 DSH Session 逻辑 |
| https://www.sqlite.org/fts5.html | FTS5 支持 unicode61、trigram 等 tokenizer、全文检索和 LIKE/GLOB 的部分索引能力 | 中文语义召回或任意短词完整覆盖 |
| https://modelcontextprotocol.io/specification/2025-11-25/basic/transports | MCP 正式文档定义 stdio、Streamable HTTP 及本地 HTTP 安全要求 | FishMemory 业务接口字段由 MCP 官方规定 |

**上游兼容性提醒**：MCP 官方文档可按协议修订版分支，DSH 文档当前指向 `master`；Codex 开发前必须固定具体 commit 与协议版本，并补充所实际依赖的版本依据。
