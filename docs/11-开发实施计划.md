# 11. Codex 开发实施计划（工作包与出口条件）

> 本文件是未来开发任务单。**当前交付不包含任何已完成实现。**

## WP-0：依赖与源码核验

- 核对 DSH release/tag/commit 和实际 API；锁定官方 MCP SDK 的协议版本。
- 核对 Qwen3.5-0.8B 的实际模型来源、许可、上下文与结构化输出能力、推理运行时适配性。
- 核对 Python、SQLite 版本、FTS5 编译可用性、中文检索表现。
- 输出：`版本锁定清单`、`DSH hook 验证笔记`、`运行环境约束`。
- 出口条件：**所有 API、字段、配置都可找到对应版本官方源码/文档**。

## WP-1：SQLite 持久记忆最小闭环

- 设计迁移、事件幂等入库、可读取原文、用户/agent 隔离、历史修正与查询。
- 不依赖本地小模型即可跑通：写入 A → 重置会话 → 读取 B → 服务重启后读取。
- 实施自测 T-01/T-02/T-04/T-05/T-06。
- 出口条件：持久化闭环可靠，无小模型也可进行确定性查询。

## WP-2：状态索引与规则检索

- 建立主题目录、摘要索引与受控搜索动作，支持分页、字节/token 限额、证据反查。
- 测试中文模糊表达和时间线更新行为；配置化回退。
- 出口条件：形成可量化 B2 基线。

## WP-3：本地小模型检索编排

- 接入可配置模型运行时，结构化规划动作受控执行。
- 多轮检索、停止条件、证据筛选、摘要压缩、无记忆判断、超时降级。
- 对模型幻觉与检索遗漏构建回归集。
- 出口条件：相比 B2 的提升/退化情况可测，不达标保留确定性模式。

## WP-4：独立 API 与 MCP Server

- 确认契约、鉴权、业务错误码、工具最小暴露；标准客户端协议测试。
- 主模型只见 `memory_recall` 读工具，敏感写删不默认暴露。
- 出口条件：独立 API 和 MCP 客户端测试通过，核心服务不依赖 DSH。

## WP-5：DSH 桥接

- 开发最小 DSH 原生插件/连接配置，分别验证 Tool Call 与受控自动预取。
- 从可信事件来源将会话内容提交给长期存储，验证事件幂等、会话重置映射与重复注入。
- 出口条件：T-03/T-11 以及 DSH 实际会话 reset 场景通过。

## WP-6：评测与质量门禁

- 构建 200+ 条（建议起点，非固定要求）标注案例，覆盖正负例、修正、跨会话、权限等。
- 对照 B0/B1/B2/B3；记录线上 API 实际费用、响应时延与 Token。
- 出口条件：所有硬性功能通过，无严重安全/隐私缺陷；形成真实数据报告。

## WP-7：部署与交付

- Linux 单机启动/安装、配置示例、备份/恢复、升级迁移、日志和监控文档。
- 适配用户的实际推理环境；如 CPU、GPU、量化方式存在差异，明确测试条件。
- 出口条件：在干净环境按说明可以复现，所有必要文件有版本声明。

## 质量要求

每个工作包必须同时提交：完整实现、自动化测试、错误/超时/重复调用处理、配置和文档更新、实际测试命令与输出、已知问题。不可只提交 Demo 或伪代码。

## 最小不可分割成果

哪怕阶段性开发中止，WP-1 + WP-2 也必须能够留下一个完整、可读、可恢复、不会丢失的 SQLite 长期记忆基础。可选模型逻辑是增强，不得成为持久化的单点故障。


## WP-3 具体补充：先非思考，后评估微调

- 本地模型必须默认 `Non-Thinking`；确认官方模型默认值，但仍需根据实际推理后端验证“关闭”是否可靠，记录每次推理模式。
- 运行时与模型统一由适配器管理；每次检索一个受限动作与少量候选；多轮循环在 Orchestrator 层，具备全局截止时间和失败回退。
- 量化模型、推理后端、模型上下文大小以及 JSON 约束生成能力都不是凭想象锁定的；以用户实际硬件测量后再定。
- 训练研究不列为开发阻断项。先对照 B2（规则/FTS）与 B3（非思考小模型），若没有稳定净收益不得强加训练依赖。

## WP-5 具体补充：可靠事件桥接

- 对 `session/event` 进行源码核验：它是 post-commit 通知，但异步监听本身不提供端到端持久交付。提供可重放事件源、待 ACK 队列或等效机制，并验证重启补偿。
- 工具接口优先通过官方 `@deepseek-ai/dsh-mcp-client` 连接；原生 DSH 插件负责会话自动化。避免为 `memory_recall` 创建两套有歧义的名称或工具实例。
- 自动预取必须避免在一次主模型工具链的每个 step 重复执行；测试会话压缩、fork、reset 时的行为。

## 发布定义补充

**不只是“能读到 SQL 行”**：必须完成跨会话恢复 + 可靠自动归档 + 证据可核查 + 线上费用 A/B + 模型关闭 Thinking 的运行验证，才算第一版 MVP。
