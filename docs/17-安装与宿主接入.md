# FishMemory 0.2：安装与宿主接入

## AstrBot：从 GitHub 安装原生插件

在 AstrBot WebUI 的插件管理中选择从仓库链接安装，填 `https://github.com/SilverIceKey/FishMemory`。仓库根的 `main.py`、`metadata.yaml`、`_conf_schema.json` 分别是原生入口、插件信息和设置表单；同目录的 `fishmemory/` 随插件一起使用，不必安装 MCP 或单独启动 HTTP 服务。宿主仍使用原来的主聊天模型。不要同时给同一机器人启用个人 MCP 配置。

也可运行 `python scripts/build_astrbot.py` 生成 `dist/astrbot_plugin_fishmemory.zip`，使用 AstrBot 本地压缩包安装入口。仓库和本地 ZIP 两条路径均已用 4.14.6 的实际安装器验证，见 [验证记录](../reports/portable-astrbot-20261104.md)。

打开 FishMemory 插件设置，设置以下项目并保存，必要时重载插件：

| FishMemory 设置 | 填写方式 |
|---|---|
| `baseUrl` | 本机 llama.cpp 示例 `http://127.0.0.1:11435/v1`。只填主机端口会自动补 `/v1`。如果 AstrBot 在 Docker 中，使用容器能访问的宿主机地址；容器的 `127.0.0.1` 指容器自己。|
| `apiKey` | llama.cpp 的 API Key 原值，不要带 `Bearer ` 前缀。这个设置保存在宿主本地配置中。|
| `apiKeyFile` | 也可让 `apiKey` 留空，提供只含一个密钥的 UTF-8 文本文件绝对路径。Windows 示例 `E:\AI\llama.cpp-cuda12\service\api-keys.txt`；容器中需填写挂载后的路径。|
| `modelId` | 默认留空。插件请求 `GET /v1/models`，只有一个 ID 即自动使用；有多个时不会猜，填写希望使用的精确 ID。|

从 v0.2.3 起，填写地址和密钥后点保存，等插件热重载，再打开插件配置。在“选择记忆模型”下拉列表中选中 ID 并保存。即使只有一个模型也可明确选中。每次保存或重载都会重新获取列表。

管理员发送 `/fishmemory_models` 可看见可用模型和所选 ID。列表及 `POST /v1/chat/completions` 均向配置的服务发送 Bearer Key；不跟随重定向。401/403 先检查密钥。写入不依赖推理服务；检索需要兼容项目非思考模式和 JSON Schema 的模型后端。模型发现并不代表每个列出的模型都适合检索。

使用支持工具调用的主模型。在**私聊**里说“记一下，茶铺风铃5826每周二休息”，再用同一账号与同一机器人开启新对话，问“风铃5826之前约定哪天休息？” 日志位于 `data/plugin_data/astrbot_plugin_fishmemory/.fishmemory/mcp-calls.jsonl`，看 `source=astrbot`、`tool`、`trace_id` 和结果 ID；数据库在同一插件数据目录下的 `memory.sqlite`。同一平台实例、同一机器人下，同一发送者账号在私聊和各群共用已有私聊记忆。群聊回答可能用到该发送者曾在私聊提供的信息。未知身份拒绝读写。不同平台实例、机器人和用户隔离；更换临时会话 ID 不换长期身份。历史 DSH 数据不会自动混入 AstrBot。

依据：[AstrBot 工具注册](https://docs.astrbot.app/dev/star/guides/ai.html)、[配置页面](https://docs.astrbot.app/en/dev/star/guides/plugin-pages.html)、AstrBot 4.14.6 发布包 `core/star/star_manager.py`、`core/star/star_tools.py`、`core/platform/astr_message_event.py`。上述设置字段均为 FishMemory 定义。

## 个人 MCP / Skill

在仓库根、Python 3.11+ 的虚拟环境中运行。下面以 Windows 为例：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install .
# 只在首次使用且没有配置时运行；已有配置请保留
.\.venv\Scripts\fishmemory init --config fishmemory.local.json
.\.venv\Scripts\fishmemory-integrate --host all --config fishmemory.local.json --output .fishmemory/host-setup
```

按实际环境填写本地 JSON 中 `model.base_url`、`model.api_key_file` 和 `model.model`。这里的通用 MCP 使用配置的模型 ID；自动发现是 AstrBot 设置功能。输出目录必须是新目录，内含可合并的宿主配置片段及 `skills/fishmemory/SKILL.md`。不要用片段覆盖已有配置。宿主必须能运行片段中的 Python 和访问配置文件；跨机器时请在目标环境生成。Skill 只规定何时调用，实际读写需要本地工具。独立 HTTP 服务通过 `fishmemory serve --config <路径>` 启动；其 HTTP 路由不是 MCP HTTP transport。

| 宿主 | 交付与使用方式 | 验证边界 |
|---|---|---|
| AstrBot | 优先上面的原生插件；`astrbot.json` 仅用于独立、单用户的 [MCP 配置](https://docs.astrbot.app/en/use/mcp.html) | 原生接口以 4.14.6 为目标 |
| DSH | 安装 `integrations/dsh-fishmemory` 中的插件并注册同一个 stdio MCP（见 docs/16）；新 bundle 只装提示插件。旧版本显式开启的 `fishmemory-archive` 需要自行关闭才能停止全量归档。 | rc.5 真实聊天读取见 reports；新版写入尚非真实会话验收 |
| Codex | 将 `codex.toml` 合并到 `~/.codex/config.toml`；Skill 目录可复制到项目 `.agents/skills/` | [OpenAI 官方 MCP](https://developers.openai.com/codex/mcp)、[Skill](https://developers.openai.com/codex/skills)；配置级验证 |
| Claude Code | `claude-code.json` 的 `mcpServers` 合并到项目 `.mcp.json`，启动后检查 `/mcp` | [官方 MCP 文档](https://code.claude.com/docs/en/mcp)；配置级验证 |
| Hermes Agent | 将 `hermes.json` 的 `mcp_servers` 合并入个人 `~/.hermes/config.yaml`；只用于私有单用户实例 | [Nous Research 配置](https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp)；配置级验证 |
| OpenCode | 按版本选择 `opencode-v1.json` 或 `opencode-v2.json`，合并到项目配置；前者 `mcp.<name>`，后者 `mcp.servers.<name>` | [V1](https://opencode.ai/docs/mcp-servers)、[V2](https://opencode.ai/v2/docs/mcp-servers)；配置级验证 |
| 通用 stdio | `generic.json` 展示启动命令及参数 | SDK 跨进程测试，不代表任意宿主实测 |

`OpelClaw` 未确认是否指 [OpenClaw](https://github.com/openclaw/openclaw)；`ZCoder` 有 [zcoder.zsh](https://github.com/ZaguanLabs/zcoder.zsh) 和近似名称 [ZCode](https://github.com/zai-org/ZCode)。暂不把这些列为已适配。

## 验证

`python -m unittest discover -s tests`、`node --test integrations/dsh-fishmemory/test/*.test.mjs`。构建并安装 wheel 后运行 `python tests/portable_smoke.py fishmemory.local.json`，在临时目录用三个独立 MCP 进程检查首次写入、重复写入、真实本地推理读回。AstrBot 使用独立测试环境 `pip install astrbot==4.14.6` 后执行 `python tests/astrbot_smoke.py fishmemory.local.json`。均使用临时库及合成消息，不会改动真实会话。

自然语言触发依赖主模型和宿主的工具权限。工具返回的静默策略约束聊天回复，不能隐藏宿主自己的工具调用记录。多人网关未做可信身份适配时禁止共用个人 MCP 配置。尚无跨宿主主模型召回率或线上成本 A/B。
