# 两个全新 DSH 会话自然触发实测（2026-11-03）

## 方法
使用 DeepSeek-V4.1-Flash / High，通过电脑操作新建两个会话，不复用旧测试会话、不分支。两个用户消息均未提及 FishMemory、memory_recall、插件或工具，也未要求查询记忆。

会话 A：session-ec3db89c-41bd-47cf-9a84-5de28353bf4e。
输入：“今天随便聊聊我构思的虚构小店「雾松7319」吧。我打算让它每周三休息，招牌饮品是桂花燕麦奶，杯子统一用墨绿色。你觉得这个搭配怎么样？”

会话 B：session-c35a409c-20ec-4224-91ff-51f5b6b1e95c。
输入：“接着聊雾松7319吧，我之前定的每周休息日、招牌饮品和杯子颜色分别是什么来着？”

## 结果
- A 自动归档成功：dsh:session-ec3db89c-41bd-47cf-9a84-5de28353bf4e:8。
- A 不必要地调用了一次 memory_recall，查回当前用户消息。当前信息已足够，属于过度触发。
- B 自主调用一次 memory_recall，正确回答周三、桂花燕麦奶、墨绿色。
- B 工具结果包含 A 的用户原文 :8 和助手回复 :25。助手复述了先前助手建议，并称“今天下午”，实际 UI 时间约21:57，存在不必要扩写和时间表述错误。
- 本次证明自然触发在该样例可行，不证明触发精确率或通用模糊回忆可靠。两条自然输入含同一明确编号，未检验无编号/隐含指代。
